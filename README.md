# WAIS-V Digit Span Test (Web)

This app implements a web-based version of the WAIS-V Digit Span test, including Forward, Backward, and Sequencing subtests. It uses the Web Speech API to present and record digit sequences, scores the results, and provides scaled scores and a Working Memory Index (WMI) based on age norms.

## Features
- Digit Span Forward, Backward, and Sequencing
- Random digit sequence generation
- Speech synthesis and recognition (Web Speech API)
- Age-based scoring using WAIS norms
- Clean, modern UI

## How to Run
1. Install dependencies: `npm install`
2. Start the app: `npm start`

## Notes
- Requires a modern browser with Web Speech API support (Chrome recommended).
- For research/educational use only.
